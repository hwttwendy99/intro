# 新用户指南

## 1. 快速开始

### 方式 A：新建文稿

点击左侧「新建」，立即进入分栏编辑模式。

### 方式 B：导入本地文件

- 点击左侧「打开」选择 `.md` 文件
- 或将 `.md` 文件拖拽到首页输入框

### 方式 C：粘贴导入

将 Markdown 文本粘贴到首页输入框，点击上传按钮。

## 2. 编辑与预览

- `Source`：适合精确编辑语法
- `Preview`：适合所见即所得编辑
- `Split`：边写边看，适合校对结构

## 3. 导出交付

点击顶部导出按钮，支持：

- `.md`
- `.txt`
- `.html`
- `.pdf`
- `.docx`

## 4. 常见问题

### 预览区富文本按钮为什么有时是灰色？

行内代码按钮需要先选中文本后才可用。
