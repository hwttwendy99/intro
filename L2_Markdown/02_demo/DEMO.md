# Demo 说明文档（本地 Markdown 编辑器）

## 1. Demo 打开方式

## 1.1 推荐方式（本地静态服务）

在项目根目录执行：

```bash
python3 -m http.server 4173
```

浏览器打开：

`http://127.0.0.1:4173/02_demo/index.html`

说明：使用本地服务可确保模块依赖与预设文档 `./docs/*.md` 正常加载。

## 1.2 直接双击 HTML（不推荐）

直接打开 `index.html` 可能受浏览器 `file://` 策略影响，导致部分能力（如预设文档 `fetch`）降级到兜底内容。

## 2. 预设文档说明

已内置 2 份预设 Markdown 文档：

- `02_demo/docs/产品功能介绍.md`
- `02_demo/docs/新用户指南.md`

加载机制：

- 页面启动时自动将以上 3 份文档加入“最近文件”列表；
- 用户可在“最近文件”中点击任一文档，切换打开并继续编辑；
- 每次新用户打开 Demo（或刷新）都会看到这三份预设文档。

## 3. 演示步骤（建议）

1. 打开页面，确认左侧“最近文件”出现 3 份预设文档。
2. 点击 `产品功能介绍.md`，进入编辑态并查看分栏模式。
3. 切换 `Source / Preview / Split`，验证三视图切换不丢内容。
4. 在预览区选中文本，演示加粗/引用/列表等富文本操作并回写源码。
5. 点击 `新用户指南.md`，验证多文档切换打开与继续编辑。
6. 演示导出能力（`.md/.txt/.html/.pdf/.docx`）。
7. 演示主题切换与中英切换，刷新后确认状态保留。

## 4. 边界说明（实现了什么 / 未实现什么）

## 4.1 当前已实现

- 本地导入能力：新建、文件选择、拖拽导入、粘贴导入
- 预设文档：3 份固定 Markdown 文档自动可见
- 三视图编辑：Source / Preview / Split
- 预览可编辑并回写 Markdown
- 撤销/恢复、复制、下载、导出、删除
- 最近文件管理：打开、搜索、重命名、创建副本、删除、导出
- 主题切换（亮/暗）与语言切换（中/英）
- 底部状态栏：字符数、路径

## 4.2 当前不实现（后续迭代）

- 用 WPS 打开
- 分享至 WPS 协作
- 文档内查找替换与高亮跳转
- 实时多人协作、云同步、插件系统
- Mermaid / 数学公式等扩展语法
