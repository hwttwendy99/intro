# 产品气质：克制的效率感

## 核心定义

KDesign 的设计语言服务于企业办公工具，核心气质是**克制的效率感**：

- **克制**：不为美观而添加视觉元素，每一个像素都应承载功能
- **效率**：用户能以最短路径完成目标任务
- **感**：在克制中仍然传递专业、可信、现代的感受

## Do（正确的感受）

### 色彩克制

- 内容区几乎纯灰度，仅品牌蓝 `#0A6CFF` 作为唯一强调色
- 语义色（红/橙/绿）仅在状态场景出现，且使用浅底+深文字的低对比组合
- 图标使用单色（`#262626` 或 `#555555`），不使用彩色填充
- 数据卡片通过文字大小和字重区分层级，不靠背景色块

### 结构清晰

- 信息组之间有明确的视觉节奏：标题（14px 600）→ 内容 → 32px 间距 → 下一组
- 同一页面内卡片和列表使用统一的组件模式（如 4 列均分卡片网格）
- 侧边栏树形结构使用统一的 32px 行高和逐级缩进
- 页面顶部面包屑 + 操作按钮的导航栏高度固定 40px

### 交互可预测

- 相似功能使用相同的交互模式（如所有设置项统一用 Radio/Switch，不混用）
- 弹窗（Modal）内的操作区域固定在底部，按钮顺序恒定：取消在左，确认在右
- 表格行内操作使用 Light Small 按钮，不使用图标按钮

## Don't（错误的感受）

### 色彩噪音

- **禁止**：每个功能入口使用不同的饱和色底图标（红色HR图标、绿色行政图标、蓝色财务图标……），这会产生视觉噪音
- **禁止**：用渐变色或阴影装饰卡片背景
- **禁止**：在非语义场景使用红色、橙色等警示色

### 模式混乱

- **禁止**：同一弹窗内混用多种交互模式（输入框 + 开关 + 列表项 + 跳转链接），每种无视觉区隔
- **禁止**：同一页面的信息组使用不同的标题样式或间距规则
- **禁止**：表单控件大小不一致（同一弹窗内混用 Medium 和 Large）

### 信息扁平

- **禁止**：所有信息平铺在页面上，没有分组和层级
- **禁止**：导航与内容之间没有视觉边界
- **禁止**：页面内容直接从 y=0 开始，没有合理的标题和引导区域

## 场景情绪引导

### 操作密集型（表格管理、列表批操作）

- 紧凑密度，行高 32px
- 工具栏与内容区紧密结合
- 操作按钮使用 Small/Medium 尺寸
- 信息密度高，但通过对齐和分组保持可扫读性

### 阅读型（文档详情、帮助中心）

- 宽松密度，正文行高 1.625
- 内容区最大宽度 720px，居中
- 段落间距 16px，标题间距 24px
- 减少操作按钮的存在感

### 决策型（仪表盘、数据概览）

- 中等密度
- 使用数据卡片突出关键指标（大字号数字 + 小字号标签）
- 卡片网格等宽排列（4 列为主）
- 趋势指标使用绿色上箭头/红色下箭头，不使用其他装饰

### 表单型（新建/编辑弹窗、设置页）

- 标准密度，控件间距 24px
- 标签左对齐或顶对齐，与控件形成清晰的问-答节奏
- 相关字段使用 Divider 或间距分组
- 必填标记（红色星号）放在标签前方

## 色彩使用时机

| 场景 | 允许使用的色彩 | 不允许 |
|---|---|---|
| 主操作按钮 | 品牌蓝 Primary | 其他颜色的 Primary |
| 链接/激活态 | 品牌蓝文字 | 下划线+颜色双重强调 |
| 成功状态 | `success-light` 底 + `success-normal` 文字 | 纯绿色大面积填充 |
| 错误状态 | `error-light` 底 + `error-normal` 文字/边框 | 纯红色大面积填充 |
| 警告状态 | `warning-light` 底 + `warning-normal` 文字 | 纯橙色大面积填充 |
| AI 功能 | `ai-normal` 紫色系 | 在非 AI 场景使用紫色 |
| 图标 | 单色（灰度） | 彩色/多色填充图标 |
| 数据趋势 | 绿色上箭头/红色下箭头 | 其他装饰性颜色 |
