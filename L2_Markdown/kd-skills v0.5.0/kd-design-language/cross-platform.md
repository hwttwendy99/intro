# 跨端一致性原则

## 三端基准

| 平台 | 设计基准宽度 | 最小字号 | 最小触控目标 | 内容密度 |
|---|---|---|---|---|
| Web | 1440px | 12px | 24px | 紧凑/标准 |
| H5（移动网页） | 375px | 12px | 44px | 标准/宽松 |
| 小程序 | 375px | 12px | 44px | 标准/宽松 |

## 共享原则（三端必须一致）

### 色彩体系

- 三端使用完全相同的 Token 色值
- 语义色映射一致（success = green-6，error = red-6）
- 品牌色依产品线一致（WPS文字 = Blue，表格 = Teal）

### 排版层级

- 标题/正文/辅助文字的字号阶梯保持一致关系
- 字重规则一致：标题 600，正文 400
- 行高倍率一致：正文 1.625，单行组件使用固定行高

### 组件语义

- 相同功能使用相同组件类型（如确认弹窗三端都用 Modal 模式）
- 按钮层级规则一致（Primary 唯一性、Danger 叠加规则）
- 反馈组件选型一致（成功用 Message/Toast，确认用 Modal）

### 图标

- 三端使用同一套 KDicon-pro 图标库
- 图标尺寸规则一致（标准 16px，按钮图标 16px）
- 不为某一端额外设计图标风格

## 允许差异的场景

### 导航方式

| Web | H5/小程序 |
|---|---|
| 侧边栏 + 顶部栏组合 | 底部 TabBar + 页面内导航 |
| 面包屑层级导航 | 返回按钮 + 页面标题 |
| Hover 展开子菜单 | 点击进入下一级页面 |

### 信息密度

| Web | H5/小程序 |
|---|---|
| 表格（多列数据对比） | 卡片列表（单条信息突出） |
| 紧凑行高 32px | 宽松行高 44-48px |
| 同页多信息组 | 分页/折叠展示 |

### 交互模式

| Web | H5/小程序 |
|---|---|
| Hover 预览、右键菜单 | 长按菜单、滑动操作 |
| Modal 居中弹窗 | 底部 ActionSheet |
| Tooltip 悬停提示 | 无（改为点击展开说明） |
| Dropdown 下拉 | Picker 滚轮选择 |

### 尺寸适配

| 元素 | Web | H5/小程序 |
|---|---|---|
| 按钮高度 | 24-36px | 36-44px |
| 输入框高度 | 28-32px | 36-44px |
| 列表项行高 | 32-48px | 44-56px |
| 卡片内边距 | 16px | 16px（保持一致） |
| 图标尺寸 | 16px | 20-24px |

## HTML 仿真多端标注

在 HTML 设计稿中标注目标平台：

```html
<!-- Web 端设计稿 -->
<div class="kd-page" data-platform="web" data-viewport="1440">
  ...
</div>

<!-- H5 端设计稿 -->
<div class="kd-page" data-platform="h5" data-viewport="375">
  ...
</div>

<!-- 小程序端设计稿 -->
<div class="kd-page" data-platform="miniprogram" data-viewport="375">
  ...
</div>
```

当同时设计多端时，按以下优先级出稿：
1. **Web 优先**（SaaS 企业应用的主要使用场景）
2. **H5 次之**（移动端访问入口）
3. **小程序**（特定业务场景）

H5/小程序的控件间距和触控目标需要显式放大，不能直接缩放 Web 版设计。
