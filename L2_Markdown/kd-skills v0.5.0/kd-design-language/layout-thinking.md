# 布局思维

## 信息密度等级

KDesign 定义三个密度等级，根据页面类型选择：

| 密度 | 行高基准 | 组间距 | 组内距 | 适用场景 |
|---|---|---|---|---|
| 紧凑 | 32px | 16-24px | 8-12px | 表格管理、列表、工具栏 |
| 标准 | 32-40px | 24-32px | 12-16px | 表单、设置页、详情页 |
| 宽松 | 40px+ | 32-48px | 16-24px | 文档阅读、帮助中心、首页概览 |

> **间距阶梯速查** → 见 [`kd-layout/spacing-system.md`](../kd-layout/spacing-system.md)
> 本文件只讲「密度/层级/留白」的决策思路，具体数值不在此重复。

## 信息层级节奏

### 页面级结构（从上到下）

```
┌─ 全局导航栏（40px）─────────────────────────┐
├─ 页面顶部栏（面包屑 + 操作按钮，40px）────────┤
├─ 页面标题区（标题 + 描述 + 标签）──────────────┤
│  spacing-xxl (32px)                          │
├─ 信息组 1（标题 + 内容）───────────────────────┤
│  spacing-xl (24px)                           │
├─ 信息组 2（标题 + 内容）───────────────────────┤
│  spacing-xl (24px)                           │
├─ 信息组 3（标题 + 内容）───────────────────────┤
└──────────────────────────────────────────────┘
```

### 信息组内部结构

```
信息组标题（14px 600）+ 右侧操作（可选）
  spacing-md (12px)
内容区域（卡片/列表/表格）
```

### 卡片内部结构

```
图标/图形区域
  spacing-md (12px)
主文本（14px 600）+ 版本标签（可选）
  spacing-xs (4px)
副文本（13px 400，text-secondary）
```

> **容器内边距 / 网格列数 / 栅格断点** → 见 [`kd-layout/web-grid.md`](../kd-layout/web-grid.md) 与 [`kd-layout/spacing-system.md`](../kd-layout/spacing-system.md)
> 本文件只谈"为什么这样切"的判断逻辑。

## 分组策略

分组决策分两层思考：

1. **容器分组**（外层）——所有浮层/面板使用底板 `#F5F5F5` 承载操作控件（标题/Tabs/按钮）。**C3 档位**额外使用白卡片 `#FFFFFF radius 12` 包裹内容区；**C1/C2 档位**内容直接在底板上。
2. **内容分组**（内容区内）——由信息复杂度决定：C1 纯字段无分组；C2 用组标题线性分组；C3a 用多白卡片区分；C3b 用 Tabs + 单卡片切换。

> **对话框（Modal）的完整判定规则、档位（C1/C2/C3a/C3b）、骨架示例、字重角色、反模式红线**一律见 [`kd-components/modal.md#信息复杂度三档-c1--c2--c3`](../kd-components/modal.md)，本文件不重复具体结构/数值，以避免双源冲突。

### 通用反模式（适用于所有浮层容器）

- C3 单层白底（缺底板 + 白卡片的容器层级） → C3 必须两层
- C1/C2 错用白卡片包裹内容 → C1/C2 内容直接在底板上
- 白卡片内叠加分割线或嵌套小卡片 → 过度容器化
- 单控件字段的 label 被加粗 600 → 应为 400（详见 [modal.md 字重判定口诀](../kd-components/modal.md)）
- 只含 1 个子字段的"伪组"出现加粗标题 → 扁平化为字段 label（组标题仅用于下层 ≥ 2 独立子字段的真组）

## 留白策略

### 页面级留白

- 页面标题下方到第一个内容区：32px
- 内容区底部到页面底部：至少 32px
- 侧边栏与内容区之间：无间距（由背景色/阴影分离）

### 组件级留白

> 具体数值 → [`kd-layout/spacing-system.md`](../kd-layout/spacing-system.md) 的「组件间间距速查」

### 避免的留白问题

- 页面底部大面积空白（应该让内容撑满或添加底部收尾元素）
- 卡片内文字与边框过近（最少 16px 内边距）
- 标题与上方内容距离 < 与下方内容距离（标题应更靠近其描述的内容）
