# 组件选型判断

> 本文件定义「为什么选这个组件」，具体「怎么用」请参考 kd-components Skill。

## 按钮层级判断

### 核心规则

- **同一视图内 Primary 按钮只能出现一次**（最核心的操作）
- Light 是默认按钮类型，不需要理由
- 超过 4 个并列操作时，次要操作收进 Dropdown

### 决策表

| 场景 | 按钮类型 | 理由 |
|---|---|---|
| 页面主操作（保存/发布/新建） | Primary | 全页只有一个最重要的动作 |
| 次要操作（暂存/导出） | Secondary | 白底有边框，与 Primary 形成层级差 |
| 取消/关闭 | Light（页面级）/ Secondary（弹窗内） | 页面级用最低权重；弹窗内用 Secondary 与主操作形成平衡 |
| 危险操作（删除） | Light + Danger | 红色文字但不占主操作位 |
| 确认删除弹窗中的删除 | Primary + Danger | 红色底，作为弹窗的唯一主操作 |
| 表格行内操作 | Light Small | 紧凑且不抢数据行的注意力 |
| 工具栏批量操作 | Light Medium 或 Secondary Medium | 中等权重 |
| **弹窗 footer 左侧辅助按钮**（默认/设置/高级选项） | **Secondary** | 白底描边，与右侧取消形成同权重但分区清晰；不用 Light 以免与取消混淆 |
| **弹窗 footer 右侧取消** | Secondary | 与左侧辅助按钮同层级 |
| **弹窗 footer 右侧确认** | Primary | 弹窗唯一主操作 |

### 按钮尺寸与场景

| 场景 | 尺寸 | 说明 |
|---|---|---|
| 页面级操作 | Large（32px） | 默认尺寸 |
| 弹窗内操作 | Large（32px） | 与页面级保持一致 |
| 表格行内操作 | Small（24px） | 紧凑 |
| 工具栏 | Medium（28px） | 中等 |
| 特殊强调（引导按钮） | X-Large（36px） | 极少使用 |

**必须遵守**：同一区域内所有按钮保持相同尺寸。

## 反馈组件选型

### 决策树

```
用户需要知道什么？
├─ 操作结果（成功/失败/提示）→ Message（全局顶部）
│  - 自动消失，不打断操作流
│  - 不需要用户确认
│
├─ 需要用户确认后继续？
│  ├─ 简单确认（删除/退出）→ Modal.confirm
│  │  - 标题 + 描述 + 取消/确认
│  │  - 危险操作：确认按钮用 Primary Danger
│  │
│  └─ 复杂内容（表单/详情）→ Modal 或 Drawer
│     ├─ 内容可在视口内完成 → Modal（480/640/800px）
│     └─ 内容较长需滚动 → Drawer（从右侧滑出）
│
├─ 悬停辅助说明？
│  ├─ 纯文字解释 → Tooltip
│  └─ 含操作/复杂内容 → Popover
│
└─ 加载状态？
   ├─ 首屏加载 → Skeleton（保持布局结构）
   ├─ 局部刷新 → Loading（旋转指示器）
   └─ 按钮提交中 → Button loading 状态
```

### Modal 尺寸选择

| 尺寸 | 宽度 | 适用内容 |
|---|---|---|
| Small | 480px | 确认弹窗、简单表单（1-3 个字段） |
| Medium | 640px | 标准表单、设置面板 |
| Large | 800px | 复杂表单、数据预览、嵌套列表 |

## 数据展示选型

### Table vs Card vs List

```
数据有多少字段？
├─ ≥5 个字段，需要对比 → Table
│  - 适合结构化、可排序、可筛选的数据
│  - 表头固定，行高 56px（含 padding）
│
├─ 2-4 个字段，强调单条信息 → Card
│  - 适合概览型展示（如功能入口、指标卡片）
│  - 使用网格布局（通常 4 列）
│
└─ 1-3 个字段，按时间/顺序浏览 → List
   - 适合动态流（如更新记录、消息列表）
   - 每条记录格式统一
```

### 何时使用 Tag

- 标记分类属性（如：社区资源 / 场景化教程 / 优质经验）
- 标记状态（但优先使用语义色 Tag：success/error/warning）
- 不用于纯装饰，Tag 内容必须有信息价值

### 何时使用 Badge

- 数字角标：未读消息数、待处理任务数
- 红点：提示有新内容但不需要精确计数
- 不用于标记状态（那是 Tag 的职责）

## 导航组件选型

### Tabs vs Segmented vs Menu

| 组件 | 适用场景 | 关键特征 |
|---|---|---|
| Tabs（Line 型） | 页面内容区切换（如不同维度的数据视图） | 有下划线指示器，内容区完整切换 |
| Tabs（Card 型） | 面板/容器内切换 | 卡片式选中态 |
| Segmented | 同一数据的展示模式切换（日/周/月，列表/网格） | 紧凑，不切换内容区 |
| 垂直 Navigation | 设置页、多模块侧边导航 | 固定在左侧 |
| Breadcrumb | 深层级页面的层级路径 | 显示在页面顶部栏 |

### 侧边栏 vs 顶部导航

- 侧边栏：功能模块 ≥3 个，且模块间独立（如知识库管理）
- 顶部导航：功能模块 ≤3 个，或全局入口（如产品切换）
- 两者可组合：顶部用于全局产品切换，侧边栏用于模块内导航

## 表单控件选型

### 输入方式判断

| 场景 | 组件 | 说明 |
|---|---|---|
| 自由文本（短） | Input | 单行输入 |
| 自由文本（长） | Textarea | 多行输入，可拖拽调整高度 |
| 从预设选项中选一个 | Select（单选） | 下拉选择 |
| 从预设选项中选多个 | Select（多选） | 多选 Tag 模式 |
| 少量选项（≤5 个）选一个 | Radio Group | 所有选项直接可见 |
| 少量选项（≤5 个）选多个 | Checkbox Group | 所有选项直接可见 |
| 开/关二选一 | Switch | 即时生效的开关 |
| 是/否二选一（表单提交后生效） | Checkbox（单个） | 勾选框 |

### 控件尺寸一致性

**硬性规则**：同一表单/区域内所有控件必须使用同一 size。

| 场景 | 控件 Size |
|---|---|
| 弹窗内表单 | Medium（28px 高） |
| 页面级表单 | Large（32px 高，默认） |
| 表格行内编辑 | Small（24px 高） |
| 搜索/筛选栏 | Medium 或 Large |
