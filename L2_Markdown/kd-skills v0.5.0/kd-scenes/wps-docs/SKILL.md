# 金山文档 (WPS Docs)

## 业务线概述

金山文档是在线协作办公平台，涵盖文字、表格、演示、PDF 等在线编辑器，以及智能文档、智能表格等新一代产品。大部分产品基于 React，文档管理器首页使用 Vue2。

## 通用约束

业务线内产品共享顶部导航框架和通用布局规则，各产品的内容区独立设计。
