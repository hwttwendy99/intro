## 语义定位

该列是**表格行拖拽排序列**，用于承载行级拖拽手柄。

它不是操作列，也不是普通图标列。判断依据：

- 列头为空
- 单元格只承载拖拽图标按钮
- 图标语义为 `dragging`
- 交互意图是调整行顺序

## 列级结构

```text
拖拽列
├── 空列头
└── 内容行 × N
    └── 单元/拖拽
        └── Icon Button / KDButton
            └── dragging icon
```

## 抽离后的列级规范

### 1. 列头

- 列头为空，不展示文字
- 列头宽度：`48px`
- 列头高度：`40px`
- 列头背景：`场景/填充/kd-color-fill-light` → `#F5F5F5`
- 列头底部分割线：`场景/线条/kd-color-line-light` → `rgba(13,13,13,0.06)`
- 列头最大高度：`60px`
- 列头内容允许 `overflow-clip`

### 2. 单元格外层

- 单元格 padding：`12px`
- 单元格底部分割线：`1px solid 场景/线条/kd-color-line-light`
- 单元格内部 gap：`2px`
- 单元格内容允许 `overflow-clip`
- 单元格只承载拖拽按钮，不追加文案

### 3. 拖拽按钮

当前样本使用 `按钮 Button / 图标按钮 Icon / KDButton`：

- 类型：`轻浅 Light`
- 状态：`normal`
- 尺寸：`M`
- 危险：`false`
- 强调：`false`
- 禁用：`false`
- 激活：`false`
- 加载中：`false`
- 图标语义：`dragging`

说明：

- 拖拽手柄必须复用图标按钮，不应直接裸放 SVG
- 拖拽语义必须使用 `dragging` 图标
- 该列不承载业务字段，不参与排序字段展示

> Token 变量完整值见 [tokens-reference.md](../../../../../../kd-foundation/tokens-reference.md)，此处不重复列举。

## 与现有样本的关系

- 与 `单选列.md` / `复选列.md` 一样，属于窄控制列
- 与 `开关列.md` 不同，拖拽列不表达布尔状态
- 与操作列不同，拖拽列只有排序手柄，不承载多个动作

## 可复用实现规则

1. 拖拽列固定为窄列，默认宽度按 `48px` 控制
2. 拖拽列列头为空
3. 拖拽手柄使用 `KDButton` 图标按钮承载
4. 拖拽列只负责排序入口，不混入行操作
5. 拖拽排序的可用、禁用、hover、dragging 状态应优先沿用按钮和拖拽交互状态

## 当前样本不应被误抽象的部分

- 不应把空列头理解为漏配列名；拖拽列列头本身就是空
- 不应把拖拽手柄替换成普通操作按钮或更多菜单
- 不应把 `dragging` 图标语义泛化为任意图标列
- 不应在拖拽列中追加业务字段、序号或状态文案
