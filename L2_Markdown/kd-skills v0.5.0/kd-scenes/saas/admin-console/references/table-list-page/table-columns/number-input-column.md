## 语义定位

该列是**表格内数字输入框列**，用于在行内编辑数字字段。

它不是纯数字展示列，也不是价格列。判断依据：

- 单元格中复用 `数字输入框 Input Number / KDInputNumber`
- 当前样本为正常编辑态
- 控件具备数字输入的专用交互结构
- 单元格用于修改字段值，而不是只读展示

## 列级结构

```text
数字输入框列
├── 列头：数字输入
└── 内容行 × N
    └── 单元/数字输入框
        └── Input Number / KDInputNumber
            └── 数字值
```

## 抽离后的列级规范

### 1. 列头

- 列宽：`160px`
- 列头文案：`数字输入`
- 列头背景：`场景/填充/kd-color-fill-light`
- 列头底部分割线：`场景/线条/kd-color-line-light`
- 列头左右 padding：`16px`
- 列头上下 padding：`8px`
- 列头内容默认左对齐

### 2. 单元格外层

- 单元格左右 padding：`8px`
- 单元格上下 padding：`10px`
- 单元格内部 gap：`2px`
- 单元格内容垂直居中
- 单元格内容允许 `overflow-clip`
- 单元格底部分割线：`1px solid 场景/线条/kd-color-line-light`

### 3. 数字输入承载

- 数字输入框宽度跟随单元格可用宽度
- 控件边框、图标和交互态由 `KDInputNumber` 本体负责
- 表格层不额外追加增减按钮
- 单元格不把数值格式拆成多个文本片段

## Input Number 本体

当前样本使用 `数字输入框 Input Number / KDInputNumber`：

- 状态：`normal`
- 尺寸：`M`
- 交互模式：`光标点控 cursorControl`
- 显示单位：`false`
- 格式前置：`false`
- 格式后置：`false`
- 当前样本未体现禁用、错误或只读状态

> Token 变量完整值见 [tokens-reference.md](../../../../../../kd-foundation/tokens-reference.md)，此处不重复列举。

## 可复用实现规则

1. 表格内可编辑数字字段必须复用 `KDInputNumber`
2. 纯展示数字不使用输入框列，应归入普通数字展示列或价格列
3. 单位、前缀、后缀属于数字输入框状态扩展，不在表格层单独拼装
4. 步进、最小值、最大值等业务规则应由输入框属性承载
5. 禁用、错误、聚焦等状态应沿用 `KDInputNumber` 本体状态

## 当前样本不应被误抽象的部分

- 不应把该列误认为价格列或容量列
- 不应把数字输入框拆成文本 + 图标按钮组合
- 不应在表格单元格层重复绘制输入框边框
- 不应把当前无单位样本推导成所有数字输入都禁止单位

## 与现有样本的关系

- 与 `文本输入框列.md` 同属行内编辑型单元格
- 与 `价格列.md` 不同，本列是可编辑控件，价格列是展示型文本
- 与 `容量大小列.md` 不同，本列不固定展示单位文本
- 与 `选择器列.md` 不同，本列编辑数值而不是枚举
