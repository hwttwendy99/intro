## 语义定位

该列是**表格内文本输入框列**，用于在行内直接编辑文本字段。

它不是普通文本列，也不是搜索框列。判断依据：

- 单元格中复用 `文本输入框 Text Field / KDTextField`
- 当前样本为已输入状态
- 输入框带清除能力
- 编辑发生在单元格内部，而不是表格外筛选区

## 列级结构

```text
文本输入框列
├── 列头：文本输入
└── 内容行 × N
    └── 单元/文本输入框
        └── Text Field / KDTextField
            └── 输入值
```

## 抽离后的列级规范

### 1. 列头

- 列宽：`160px`
- 列头文案：`文本输入`
- 列头背景：`场景/填充/kd-color-fill-light`
- 列头底部分割线：`场景/线条/kd-color-line-light`
- 列头左右 padding：`16px`
- 列头上下 padding：`8px`
- 列头内容默认左对齐

### 2. 单元格外层

- 单元格左右 padding：`8px`
- 单元格上下 padding：`10px`
- 单元格内部 gap：`2px`
- 单元格内容垂直居中
- 单元格内容允许 `overflow-clip`
- 单元格底部分割线：`1px solid 场景/线条/kd-color-line-light`

### 3. 输入框承载

- 输入框宽度跟随单元格可用宽度
- 输入框不额外叠加表格自定义边框
- 输入框状态由 `KDTextField` 本体负责
- 表格行高由单元格 padding 和输入框 M 尺寸共同决定

## Text Field 本体

当前样本使用 `文本输入框 Text Field / KDTextField`：

- 状态：`normal`
- 尺寸：`M`
- 输入状态：`已输入 entered`
- 清除内容：`true`
- 前置图标：`false`
- 前置元素：`false`
- 密码框：`false`
- 后置图标：`false`
- 后置文本：`false`
- 后置图标按钮：`false`
- 字数统计：`false`
- 前置选择：`false`
- 后置选择：`false`

## 可复用实现规则

1. 表格内可编辑文本字段必须复用 `KDTextField`
2. 只读文本字段应退回普通文本列，不保留输入框壳层
3. 输入框列的外层 padding 通常小于普通文本列，用于容纳控件边框
4. 清除按钮属于输入框本体状态，不作为表格列额外按钮处理
5. 校验错误、禁用、聚焦等状态应作为 `KDTextField` 状态扩展，不自定义表格态

## 当前样本不应被误抽象的部分

- 不应把输入框里的样本文案沉淀为固定值
- 不应把该列当作筛选栏搜索输入框
- 不应把 `KDTextField` 退化成无边框纯文本
- 不应在单元格层级重复绘制输入框边框

## 与现有样本的关系

- 与 `数字输入框列.md` 同属行内编辑型单元格
- 与 `选择器列.md` 不同，本列编辑自由文本而不是枚举值
- 与 `日期时间列.md` 不同，本列可编辑，日期时间列当前只展示
- 与普通文本展示列不同，本列必须保留控件态与输入语义
