## 语义定位

该列是**管理后台表格中的单选列**，用于在多行数据中选择唯一一行。

当前样本特征：

- 列宽固定：`48px`
- 列头为空
- 单元格只承载 `Radio`
- 当前样本均为未选中态
- 不展示 label、辅助文本、前置图标或增值标识

它不是复选列。判断依据：

- 单选列用于“多选一”
- 复选列用于批量选择或多选
- 组件语义必须复用 `Radio / KDRadio`，不应使用 checkbox 代替

## 列级结构

```text
单选列
├── 空列头
└── 内容行 × N
    └── 单元/单选
        └── Radio / KDRadio
```

## 抽离后的列级规范

### 1. 列头

- 列头为空，不展示文字
- 列头高度：`40px`
- 列头宽度：`48px`
- 列头背景：`场景/填充/kd-color-fill-light` → `#F5F5F5`
- 列头底部分割线：`场景/线条/kd-color-line-light` → `rgba(13,13,13,0.06)`
- 列头最大高度：`60px`
- 列头内容允许 `overflow-clip`

### 2. 列宽

- 固定宽度：`48px`
- 最小宽度：`48px`

说明：

- 单选列是选择控制列，宽度不随业务文案变化
- 不应因为表格字段变多而压缩到小于 `48px`

### 3. 单元格外层

- 单元格 padding：`16px`
- 单元格底部分割线：`1px solid 场景/线条/kd-color-line-light`
- 单元格内部 gap：`2px`
- 单元格内容允许 `overflow-clip`
- 当前样本内容横向从单元格起点开始，不额外添加文本

结论：

- 单选列属于**行选择型单元格**
- 它是选择控制，不是业务字段展示

### 4. Radio 本体

当前样本使用 `单选框 / KDCheckBox` Code Connect 包裹的 `Radio` 组件，属性如下：

- 状态：`normal`
- 选中：`false`
- 禁用：`false`
- 文本描述：`false`
- 辅助文本：`false`
- 前置图标：`false`
- 增值标识：`false`

说明：

- 当前样本为未选中态
- 如果后续样本出现选中态、禁用态，应补充为同一列型下的状态样本
- 不要在单元格内额外放置“选择”文案

### 5. Radio 视觉变量

当前样本读取到未选中态相关变量：

- Radio 填充：`场景/填充/kd-color-fill-base` → `#FFFFFF`
- Radio 边线：`场景/线条/kd-color-line-heavy` → `rgba(13,13,13,0.48)`

这些变量用于识别 `Radio` 的未选中态，不建议在表格列规则中重新定义组件内部尺寸。

> Token 变量完整值见 [tokens-reference.md](../../../../../../kd-foundation/tokens-reference.md)，此处不重复列举。

## 与现有样本的关系

### 与 `复选列.md` 的区别

- `复选列.md` 支持多选、全选和半选态
- `单选列.md` 用于唯一行选择，不存在半选态

### 与 `开关列.md` 的区别

- `开关列.md` 表达行内布尔配置
- `单选列.md` 表达当前行是否为唯一选中项

### 与 `状态列.md` 的区别

- `状态列.md` 是信息展示
- `单选列.md` 是选择控制

## 可复用实现规则

基于当前样本，可以先形成这些中间判断：

1. 单选列与复选列都属于**行选择型单元格**
2. 单选列固定宽度为 `48px`
3. 单选列列头为空，不放全选控件
4. 单选列应复用 `Radio / KDRadio`，不应复用 `Checkbox`

## 当前样本不应被误抽象的部分

- 不应把空列头理解为漏配列名；单选列列头本身就是空
- 不应把单选列替换成复选列，二者选择语义不同
- 不应在单选列列头追加全选控件
- 不应把当前未选中态推导为单选列不需要选中态
