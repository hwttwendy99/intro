## 语义定位

该列是**管理后台表格中的“图标 + 主标题 + 次标题”图文列**，适合承载：

- 应用名称
- 产品名称
- 能力名称
- 资源名称
- 任何“有品牌图标 / 业务图标 + 主信息 + 辅助归属信息”的列表字段

从当前样本看，主信息为应用名称，辅助信息为归属方（示例中为“金山办公”）。

## 列级结构

```text
图文列
├── 固定列背景（可选，用于左侧固定列）
├── 列头
│   └── 表头文字
├── 内容行 × N
│   └── 图文单元
│       ├── 图标容器
│       │   └── 24px 图标 / Logo
│       └── 内容区
│           ├── 主标题
│           └── 次标题
└── 固定列右侧分割线（固定列模式下出现）
```

## 抽离后的列级规范

### 1. 列头

> 通用列头样式（背景、分割线、padding、文字）见 `README.md#通用列头规范`。

（本列无特有列头属性）

### 2. 单元格外层

- 每行单元底部有 `1px` 分割线
- 分割线颜色：`场景/线条/kd-color-line-light`
- 单元格左右 padding：`16px`
- 单元格上下 padding：`12px`
- 单元格内部最外层 gap：`2px`
- 单元格内容区域宽度策略：`w-full + min-w-px + flex-1`
- 该列属于**可伸缩内容列**，但当前样本宽度为 `200px`

### 3. 图文内容布局

- 内容主结构为：`图标容器 + 文本内容区`
- 图标与文本区之间 gap：`12px`
- 图标容器固定为 `24px`
- 文本内容区使用纵向布局，两行文本上下堆叠
- 文本内容区需支持 `min-width: 0`

### 4. 图标容器

- 图标容器可视区域：`24px × 24px`
- 当前样本图标全部以 `24px` 图标 / Logo 规格承载
- 图标容器应居中承载图标，不参与拉伸
- 不同业务图标允许拥有自身品牌色，但**品牌图标本身的颜色不属于表格列公共 token**

#### 图标容器边框笔触参考

来自 Figma 组件描述：

- `8` 使用 `1px`
- `12` 使用 `1px`
- `16` 使用 `1.5px`
- `20` 使用 `1.5px`
- `24` 使用 `2px`

因此该列如使用描边式 `24px` 图标，默认按 `2px` 描边厚度理解。

### 5. 主标题

- 颜色：`var(--kd-color-text-primary)` → `#0D0D0D`
- 字号：`13px`
- 行高：`20px`
- 字重：`400`
- 放置方式：文本行外再包一层 `py: 2px` 的标题行容器
- 标题区需允许横向压缩，不得因为长文本挤压图标

### 6. 次标题

- 颜色：`var(--kd-color-text-secondary)` → `#6B6B6B`
- 字号：`12px`
- 行高：`20px`
- 字重：`400`
- 次标题宽度跟随内容区 fill
- 典型用途：
  - 所属组织
  - 所属团队
  - 品牌 / 厂商
  - 辅助说明

## 固定列特征

这个节点本身带有明显的**左侧固定列**特征：

- 整列底板：`场景/背景/kd-color-background-bottom` → `#FFFFFF`
- 阴影：`浅色/阴影/kd-box-shadow-large` → `0 12px 32px 0 rgba(13,13,13,0.08)`
- 整列右侧有固定分隔线：`border-right: 1px solid 场景/线条/kd-color-line-light`

结论：

- “图文列”本身是列内容模式
- 当前样本同时展示了**固定左列版图文列**
- 后续若复用到非固定列场景，应拆分理解：
  - **列内容规范**可以复用
  - **固定列背景 / 阴影 / 右侧分隔线**仅在 fixed 列场景下启用

> Token 变量完整值见 [tokens-reference.md](../../../../../../kd-foundation/tokens-reference.md)，此处不重复列举。

## 可复用实现规则

### HTML / 前端实现建议

- 单元格内容推荐结构：

```text
td
└── .cell-media-text
    ├── .cell-media-text__icon
    └── .cell-media-text__content
        ├── .cell-media-text__title
        └── .cell-media-text__meta
```

- 推荐样式约束：
  - `.cell-media-text` 使用 `display:flex`
  - `gap: 12px`
  - `align-items: flex-start`
  - `min-width: 0`
  - 图标容器 `flex: 0 0 24px`
  - 文本容器 `flex: 1 1 auto; min-width: 0`
  - 标题与副标题保持两行层级，不要压成单行 inline

### 文本截断建议

从样本看是短文本，未直接展示截断态，因此当前先只抽离保守规则：

- 标题与副标题都应允许后续接入单行截断
- 当页面列宽不足时，优先截断文本，不压缩图标
- 标题和副标题若都需要截断，优先保证标题可读性

## 当前样本不应被误抽象的部分

以下信息暂不视为“图文列公共规范”：

- 每个具体业务 Logo 的品牌颜色
- 图标内部矢量形状
- 示例文本“日历 / 表单 / 邮箱 / 金山办公”等业务数据
- 列宽 `200px` 作为所有图文列的固定宽度

这些只属于当前样本数据，不属于通用列规范。

## 与现有表格规则的关系

该样本与现有 `table.md` 可以互补：

- `table.md` 负责表格通用框架、行高、悬停、选中、滚动、固定列逻辑
- 本文件负责“图文列”这种具体列内容模式

因此后续如果继续喂养：

- 状态列
- 标签列
- 数值列
- 操作列

建议都继续放在 `table-columns/` 下，以便后面统一抽象为表格列规范。

该补充样本是**文件名图文列**：

- 列宽：`200px`
- 列头文案：`文件名`
- 单元格结构：`24px 文件类型图标 + 文件名文本`
- 图标与文本 gap：`12px`
- 单元格 padding：左右 `16px`，上下 `12px`

- `flow_chart_format_24`
- `mind_mapping_format_24`
- `wps_format_24`
- `wpp_format_24`
- `ap_format_24`
- `ebooks_format_24`
- `pdf_format_24`

补充判断：

- 图文列可以分为“业务图标 + 主副标题”和“文件图标 + 文件名”两类
- 文件名图文列不需要副标题时，应保持单标题结构
- 文件类型图标必须使用 24px 文件格式图标，不应使用通用占位图标
