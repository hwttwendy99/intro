## 语义定位

该列是**标签 / 标签组列**，用于在单元格内展示多个普通业务标签。

它不是成员标签列，也不是风险等级列。判断依据：

- 单元格内出现多个 `KDTag`
- 标签为普通灰色标签，不承载头像、成员身份或风险等级色
- 标签集合允许换行
- 标签文本是业务分类信息，而不是操作入口

## 列级结构

```text
标签列
├── 列头：标签&标签组
└── 内容行 × N
    └── 单元/标签组
        ├── Tag / KDTag
        ├── Tag / KDTag
        └── Tag / KDTag
```

## 抽离后的列级规范

### 1. 列头

- 列宽：`244px`
- 最小宽度：`197px`
- 列头文案：`标签&标签组`
- 列头背景：`场景/填充/kd-color-fill-light`
- 列头底部分割线：`场景/线条/kd-color-line-light`
- 列头左右 padding：`16px`
- 列头上下 padding：`8px`
- 列头内容默认左对齐

### 2. 单元格外层

- 单元格左右 padding：`16px`
- 单元格上下 padding：`12px`
- 单元格外层 gap：`2px`
- 单元格底部分割线：`1px solid 场景/线条/kd-color-line-light`
- 单元格内容允许 `flex-wrap`
- 多标签内容按顶部起始位置排列，不垂直压缩标签本体

### 3. 标签集合

- 标签集合内部 gap：`8px`
- 标签集合水平排列，空间不足时换行
- 标签数量可为多个，不以当前样本数量作为上限
- 标签之间不使用逗号或斜杠替代

## Tag 本体

当前样本使用 `标签 Tag / KDTag`：

- 图标：`false`
- 边框：`false`
- 尺寸：`M`
- 颜色：`gray`
- 状态：普通展示态
- 交互：当前样本未体现点击、关闭或编辑


> Token 变量完整值见 [tokens-reference.md](../../../../../../kd-foundation/tokens-reference.md)，此处不重复列举。

## 可复用实现规则

1. 普通业务标签组必须复用 `KDTag`
2. 多标签单元格必须支持换行，不能通过缩小字号硬塞在一行
3. 普通标签默认使用 `gray` 色，不借用风险、状态或成员标签色
4. 标签列宽应给出最小宽度，避免多标签内容被压缩到不可读
5. 如果标签具备关闭、编辑、点击筛选等能力，应作为交互变体补充，不覆盖基础展示态

## 当前样本不应被误抽象的部分

- 不应把当前标签文案沉淀为固定业务枚举
- 不应把普通标签列合并到成员标签列
- 不应把普通标签色升级为状态色或风险色
- 不应用纯文本分隔符替代 `KDTag` 本体

## 与现有样本的关系

- 与 `成员标签列.md` 不同，本列不展示成员头像或身份组合
- 与 `风险等级列.md` 不同，本列不承载风险级别颜色语义
- 与 `地点列.md` 不同，本列的多个内容是独立标签，不是连续路径
- 与 `状态列.md` 不同，本列可出现多个标签，状态列通常表达单一状态
