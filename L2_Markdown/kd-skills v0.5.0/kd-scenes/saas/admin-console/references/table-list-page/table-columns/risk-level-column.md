## 语义定位

该列是**管理后台表格中的风险等级列**，用于表达记录当前的风险分层，而不是业务状态、成员身份或操作结果。

当前样本呈现出三档风险：

- `高风险`
- `中风险`
- `低风险`

它们都采用 **KDTag 风格标签** 承载，不使用图标，也不使用裸文本。

## 列级结构

```text
风险等级列
├── 列头
│   └── 表头文字
└── 内容行 × N
    └── 单元/风险等级
        └── 风险标签 / KDTag
            └── 风险文案
```

## 抽离后的列级规范

### 1. 列头

> 通用列头样式（背景、分割线、padding、文字）见 `README.md#通用列头规范`。

### 2. 单元格外层

- 单元格左右 padding：`16px`
- 单元格上下 padding：`12px`
- 单元格底部分割线：`1px solid 场景/线条/kd-color-line-light`
- 单元格内容垂直居中
- 单元格内部不直接摆放文本，而是使用轻量标签承载风险等级

结论：

- 风险等级列属于**标签型单元格**
- 但它不同于成员标签列：这里只承载语义等级，不承载头像、多人集合或可删除交互

### 3. 风险标签

当前单元内容为 `KDTag` 风格标签，结构稳定且轻量：

- 不带图标：`图标Icon = false`
- 不带边框：`边框Border = false`
- 尺寸：`M`
- 标签圆角：`kd-border-radius-100` → `4px`
- 标签内部左右 padding：`12px`
- 标签内部上下 padding：`2px`

说明：

- 这是**纯文本等级标签**
- 风险等级依赖背景色和文字色建立语义，不依赖图标辅助

### 4. 风险文案

风险文案统一：

- 字号：`13px`
- 行高：`20px`
- 字重：`400`
- 单行显示

### 5. 风险等级与颜色映射

#### 高风险

- 标签底色：`基础/red/kd-color-red-1` → `#FEF1F1`
- 文本颜色：`kd-color-text-error` → `#BB2726`
- 推荐语义：高危、需重点关注、需立即处理

#### 中风险

- 标签底色：`基础/yellow/kd-color-yellow-1` → `#FCF2E0`
- 文本颜色：`kd-color-text-warning` → `#C25010`
- 推荐语义：存在一定风险、需跟进、待观察

#### 低风险

- 标签底色：`基础/verdure/kd-color-verdure-1` → `#EFF6D4`
- 文本颜色：`基础/verdure/kd-color-verdure-7` → `#667F00`
- 推荐语义：低风险、相对稳定、可常规跟进

## 与现有样本的关系

### 与 `状态列.md` 的区别

- `状态列.md` 是“图标 + 文本”的状态型单元格
- `风险等级列.md` 是“纯文本标签”的等级型单元格

### 与 `成员标签列.md` 的区别

- `成员标签列.md` 的标签内还承载 `Avatar + 姓名`
- `风险等级列.md` 只承载单一语义文案

### 与 `成员组标签列.md` 的区别

- `成员组标签列.md` 是多标签集合
- `风险等级列.md` 是每个单元仅一个标签

## 可复用实现规则

基于当前样本，可以先形成这些中间判断：

1. **标签型单元格** 至少可以分成三类：
   - 身份标签型
   - 集合标签型
   - 等级标签型
2. **等级标签型单元格** 更依赖颜色语义，不依赖图标
3. 风险、优先级、严重度这类字段，后续大概率都可以复用这一模式

## 当前样本不应被误抽象的部分

- 不应把当前风险文案沉淀为唯一等级全集
- 不应把风险等级色挪给普通业务标签使用
- 不应把等级标签列和状态列混为一类；状态列通常是图标 + 文本
- 不应因为当前样本无图标，就禁止其他等级体系扩展图标变体
