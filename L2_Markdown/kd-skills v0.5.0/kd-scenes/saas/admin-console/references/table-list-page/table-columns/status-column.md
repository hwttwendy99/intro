## 语义定位

该列是**管理后台表格中的状态列**，用于表达记录的当前业务状态，而不是操作结果或临时提示。

当前样本出现的典型状态有：

- `已启用`
- `管理员禁用`
- `未启用`

它们都采用“图标 + 状态文本”的组合方式呈现。

## 列级结构

```text
状态列
├── 列头
│   └── 表头文字
└── 内容行 × N
    └── 单元/状态
        └── 状态元素
            ├── 状态图标
            └── 状态文本
```

## 抽离后的列级规范

### 1. 列头

> 通用列头样式（背景、分割线、padding、文字）见 `README.md#通用列头规范`。

### 2. 单元格外层

- 单元格左右 padding：`16px`
- 单元格上下 padding：`12px`
- 单元格底部分割线：`1px solid 场景/线条/kd-color-line-light`
- 单元格内容纵向居中
- 单元格内部不使用标签壳层，不使用 pill 容器

结论：

- 状态列是**纯内容组合型单元格**
- 状态信息直接落在单元格中，不再额外包裹背景色容器

### 3. 状态元素

状态元素由：

- `12px` 状态图标
- `13px` 状态文本

组成，二者之间 gap 为 `4px`。

这是一种比标签列更轻量的表达方式，适合高频、列表化的状态展示。

### 4. 状态图标

当前样本使用了三类图标：

- `successful`
- `circle_slash`
- `circle_horizontal_line`

图标尺寸统一为 `12px`。

图标容器本身不带额外背景，也不扩展成按钮。

### 5. 状态文本

文本统一：

- 字号：`13px`
- 行高：`20px`
- 字重：`400`
- 单行显示

但不同状态映射不同语义色：

#### 已启用

- 图标色：`场景/图标/kd-color-icon-success` → `#418F1F`
- 文本色：`kd-color-text-success` → `#347317`

#### 管理员禁用

- 图标色：`场景/图标/kd-color-icon-red-primary` → `#BF3942`
- 文本色：`kd-color-text-error` → `#BB2726`

#### 未启用

- 图标色：`kd-color-icon-secondary` → `#757575`
- 文本色：`var(--kd-color-text-secondary)` → `#6B6B6B`


> Token 变量完整值见 [tokens-reference.md](../../../../../../kd-foundation/tokens-reference.md)，此处不重复列举。

## 可复用实现规则

### HTML / 前端实现建议

推荐结构：

```text
td
└── .cell-status
    └── .status-inline
        ├── .status-inline__icon
        └── .status-inline__label
```

推荐样式语义：

- `.cell-status`
  - `display: flex`
  - `align-items: center`
- `.status-inline`
  - `display: inline-flex`
  - `align-items: center`
  - `gap: 4px`

### 组件复用原则

- 状态列优先使用语义图标 + 文本，不要误用 `Tag` 容器
- 状态列优先表达“记录状态”，不要混入按钮行为
- 若后续需要可点击状态，则应单独定义交互规则，而不是直接复用当前样本

## 与现有样本的关系

该样本与已有标签类样本形成清晰对照：

- `成员标签列` / `成员组标签列`：标签壳层明显存在
- `状态列`：没有标签壳层，只有轻量图标 + 文本

这说明后续可以把单元格内容模式先粗分为两大类：

1. **标签型单元格**
2. **内联状态型单元格**

## 当前样本不应被误抽象的部分

以下信息暂不视为公共规范：

- 当前具体状态文案只包含这三种
- 所有状态都必须用圆形图标
- 当前列宽 `113px` 作为所有状态列固定宽度

其中：

- `113px` 更适合作为当前业务参考值
- 状态类型、状态图标和状态文案集合需要结合更多业务样本再统一归纳

## 当前判断

现在样本库已经出现新的归纳边界：

- 标签型单元格：成员标签列、成员组标签列
- 内联状态型单元格：状态列

如果后续再出现：

- 更多状态列
- 风险状态列
- 审批状态列
- 上下线状态列

就可以开始抽出一个 `状态型单元格规范.md`。
