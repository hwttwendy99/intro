## 语义定位

该列是**管理后台表格中的开关列**，用于在行内直接表达或切换某个布尔状态。

当前样本表头为：

- `启用`

单元格内容为：

- `KDSwitch`
- 关闭态
- 无前置文本
- 非 loading
- 非 disabled

它不是状态文本列，也不是复选列。判断依据：

- 开关用于表达单个布尔配置是否启用
- 用户可以直接在行内切换
- 组件语义应复用 `KDSwitch`，不应使用 checkbox 或自定义滑块替代

## 列级结构

```text
开关列
├── 列头

```

## 抽离后的列级规范

### 1. 列头

> 通用列头样式（背景、分割线、padding、文字）见 `README.md#通用列头规范`。

### 2. 单元格外层

- 单元格 padding：`16px`
- 单元格底部分割线：`1px solid 场景/线条/kd-color-line-light`
- 单元格内容垂直居中
- 单元格内部 gap：`8px`
- 单元格内容允许 `overflow-clip`
- 单元格内部只承载开关本体，不额外添加状态文案、标签或图标

结论：

- 开关列属于**布尔控制型单元格**
- 它既不是展示型状态，也不是批量选择控件

### 3. 开关本体

当前样本使用 `开关 / KDSwitch` 组件，属性如下：

- 状态：`normal`
- 开关：`false`
- 前置文本：`false`
- 加载中：`false`
- 禁用：`false`

说明：

- `开关=false` 表示当前行处于关闭 / 未启用状态
- 如果后续样本出现 `true`、`loading`、`disabled`，应补充成同一列型下的状态样本
- 不要用静态灰色 pill 或图形模拟 Switch

### 4. 开关视觉变量

当前样本读取到关闭态相关变量：

- 开关轨道圆角：`开关/关/Radius` → `22`
- 拇指颜色：`基础/kd-color-white` → `#FFFFFF`
- 关闭态轨道色：`基础/gray/kd-color-gray-6` → `#919191`

这些变量用于识别 `KDSwitch` 的关闭态，不建议在表格列规则中重新定义组件内部尺寸。

> Token 变量完整值见 [tokens-reference.md](../../../../../../kd-foundation/tokens-reference.md)，此处不重复列举。

## 与现有样本的关系

### 与 `复选列.md` 的区别

- `复选列.md` 用于行选择或批量选择
- `开关列.md` 用于行内布尔配置切换

### 与 `状态列.md` 的区别

- `状态列.md` 是展示型状态，由图标和文本表达
- `开关列.md` 是可交互控件，用户可以直接修改行状态

### 与 `风险等级列.md` 的区别

- `风险等级列.md` 使用标签表达等级
- `开关列.md` 使用控件表达布尔值

## 可复用实现规则

基于当前样本，可以先形成这些中间判断：

1. 表格中可直接启停的字段，应归为**布尔控制型单元格**
2. 开关列必须复用 `KDSwitch`
3. 开关列默认不追加状态文案；如需展示启用/停用文本，应另行判断是否拆成状态列或组合型单元格
4. 开关列的具体内部视觉由 `KDSwitch` 组件负责，表格列只控制单元格承载方式

## 当前样本不应被误抽象的部分

- 不应把开关列当作行选择列
- 不应用状态标签替代可交互开关
- 不应在开关旁默认追加“启用/停用”文案
- 不应把当前状态推导为所有开关列默认值
