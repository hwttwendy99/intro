# 文本展示型列

本文件统一定义管理后台表格中**所有纯文本展示列**的规范。这些列共享相同的单元格结构和文字样式，仅在语义、对齐方向和格式化规则上有差异。

## 通用单元格规格

所有文本展示型列共享以下规格（不再在各列中重复）：

- 列头样式：见 `README.md#通用列头规范`
- 单元格左右 padding：`16px`
- 单元格上下 padding：`12px`
- 单元格底部分割线：使用 `inset box-shadow`、伪元素或等价不占高方案绘制 `1px` 分割线，不使用参与行高计算的真实 `border-bottom`
- 单元格内部 gap：`2px`
- 单元格内容允许 `overflow-clip`
- 文本字号：`13px`
- 文本行高：`20px`
- 文本字重：`400`
- 文本颜色：`var(--kd-color-text-primary)`
- 空值显示 `-`，使用 `var(--kd-color-text-secondary)`

## 各列特有规则

### 编号列

- 保留前导零，不得把 `001` 转成 `1`
- 虽内容为数字，语义是标识，不右对齐
- 样本：`001`、`002`、`010`

### 价格列

- 右对齐，便于纵向比较数值大小
- 保留千分位分隔符
- 展示格式由业务格式化层输出，单元格只承载格式化后文本
- 如需可编辑态，应切换到数字输入框列
- 样本：`320`、`1,560`、`45,780`

### 容量大小列

- 右对齐，便于纵向比较
- 数值与单位保持在同一文本节点（如 `624.36 KB`）
- 可扩展到 B / KB / MB / GB / TB 等单位
- 如果业务强调使用率，应另行使用进度/比例列
- 样本：`624.36 KB`、`721.07 KB`

### 网络地址列

- IP 地址作为字符串展示，不做数字格式化
- 默认不自动变成链接
- IPv6 场景需补充更宽列宽或截断策略
- 样本：`192.168.1.45`、`10.0.2.189`

### 联系方式列

- 脱敏逻辑由数据层完成，单元格只展示脱敏后的值
- 默认不自动生成拨号链接
- 样本：`138****8000`、`139****5678`

### 邮箱列

- 按原始字符串展示，不自动生成 `mailto:` 链接
- 如果业务要求点击发送邮件，应改按链接列处理
- 列宽不足时优先截断文本，不压缩字号
- 样本：`tianxinyi@wps.cn`、`pengze@wps.cn`

### 日期时间列

- 默认完整格式：`YYYY-MM-DD HH:mm:ss`
- 数字和分隔符必须完整展示，不随意省略秒
- 不是日期选择器——只有出现行内编辑需求时才升级为日期控件列
- 排序/筛选入口应放在表头或筛选区，不在单元格内追加控件
- 样本：`2025-03-13 05:06:08`

### 地点列

- 多级行政区划使用 `/` 连接路径，不拆成多个 Tag
- 超长路径按表格文本截断策略处理，不拆多行
- 省市区筛选交给筛选区或表头筛选
- 样本：`中国/北京市/北京市/东城区`

## 可复用实现建议

```text
td
└── .cell-text (或 .cell-text.is-align-end 用于右对齐列)
    └── .cell-text__content
```

- 左对齐列：默认 `text-align: left`
- 右对齐列（价格、容量）：`.is-align-end` 同时作用于列头和单元格
- 所有列保持单行，溢出时截断（`white-space: nowrap; overflow: hidden; text-overflow: ellipsis`）
- 地点列若业务允许换行，可使用 `white-space: normal`

## 不应被误抽象的内容

- 各列推荐宽度仅为样本参考值
- 各列样本文案不代表业务取值范围或枚举全集
- 展示型文本列与行内编辑型控件列必须分开，不能用只读控件壳层替代普通文本
- 不应因为内容全是数字就默认右对齐——只有可比较数值（价格、容量）才右对齐

## 演化方向

当前 8 列可进一步归为子类：

1. **短标识列**：编号、网络地址（短/定长文本）
2. **右对齐数值列**：价格、容量（可比较数值）
3. **长文本标识列**：邮箱、联系方式、地点（长/变长文本）
4. **格式化文本列**：日期时间（固定格式）

后续新增文本展示列时，先判断归入哪个子类，复用本文件规则即可。

## 标题 / 名称类纯文本补充

- 若字段只承担信息展示，不承担详情跳转或资源打开语义，应按普通文本列实现。
- 纯文本标题 / 名称列在 hover 时不得机械变蓝，不得仅通过颜色变化模拟链接态。
- 只有明确命中真实跳转语义时，才切换到 `link-column.md` 定义的链接型列。
