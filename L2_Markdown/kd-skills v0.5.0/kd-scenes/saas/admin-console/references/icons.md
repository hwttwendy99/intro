# 图标

## 图标规则

1. 所有功能图标必须优先使用 KDIcon pro 语义图标。
2. 禁止用纯文本字符替代图标，例如 `>`, `<`, `/`, `v`, `...`。
3. HTML 预览可用内联 SVG 模拟 KDIcon pro，但必须保持 16x16、线性、单色、圆角端点/连接的风格。

## 常用图标映射

| 场景 | KDIcon pro 图标 |
|---|---|
| 搜索输入框前置图标 | `magnifier` |
| 导航展开 | `arrow_up_s` |
| 导航收起 | `arrow_down_s` |
| 面包屑分隔 | `arrow_right_s` |
| 会员功能标识 | `vip_service` |
| 分页上一页 | `arrow_left_s` |
| 分页下一页 | `arrow_right_s` |
| Select 下拉 | `arrow_down_s` |
| 更多页码 | `more` |
| 导航底部收起侧栏 | `arrow_left_double_s` |
