# Modal 组合模式

> **定位**：本文件定义 Modal 容器内的信息组织模式（C1-C3 分档、字重体系、尺寸预算）。
> 属于 Layer 2 kd-patterns，适用于所有输出目标（HTML / React / Vue / QT JSON）。
> 具体 CSS 实现见 [kd-components/modal.md](../kd-components/modal.md)；React API 见 [kd-react/docs/components/modal.md](../kd-react/docs/components/modal.md)。

## 跨技术栈组件名映射

本文件使用「Modal」作为设计模式术语。各技术栈的**实际组件名**不同，生成代码时必须使用目标技术栈的组件名：

| 输出目标 | 组件名 | 标签 / 调用 | 来源 |
|---------|--------|------------|------|
| HTML 设计稿 | Modal | `.kd-modal` | `kd-components/modal.md` |
| React | Modal | `<Modal>` / `import { Modal } from '@kdocs/kdesign'` | `kd-react/components/modal/` |
| Vue3 | **Dialog** | `<kd-dialog>` / `import { KdDialog } from '@kdocs/kdesign-vue3'` | `kd-vue3/components/kd-dialog/` |

> **特别注意**：Vue3 中**没有 `KdModal` 组件**，必须使用 `KdDialog`。

## Modal 信息复杂度分档（C1 / C2 / C3）

对话框按信息复杂度分**四种形态**（C3 再细分 a/b）。生成任何目标的代码前必须先判定档位，再套对应结构。

### 判定表（自上而下匹配，命中即停）

| 档位 | 触发条件 | 内容承载方式 | 白卡片 | 卡片间 gap |
|------|---------|------------|--------|-----------|
| **C3b** 切换型 | 出现 Tabs / Segmented（优先级最高） | 底板 + **1 张**白卡片（多卡片即违规） | 1 张 | — |
| **C3a** 多卡片复杂型 | 无 Tabs，需多卡片（形态差异大 / 横向布局） | 底板 + **多张**白卡片 | 多张 | 8px |
| **C2** 线性复合型 | 无 Tabs，无多卡片，**≥ 1 个真组** | 内容**直接在底板上**，不包裹白卡片 | 无 | — |
| **C1** 纯字段型 | 无 Tabs，无多卡片，**无真组** | 内容**直接在底板上**，不包裹白卡片 | 无 | — |

> **C1 定义**：只要一个真组都没有（全是 `label + 单控件`），不论字段数量多少，都是 C1。
> **C1/C2 分界线** = 本弹窗是否至少出现 1 个真组。

### 决策流

```
① 有 Tabs / Segmented 切换？
    ├─ 是 → C3b（单张白卡片，多卡片即违规）
    └─ 否 → ②
② 需要多白卡片区分（形态差异大 / 分组横向布局）？
    ├─ 是 → C3a（多张白卡片）
    └─ 否 → ③（C1/C2 均无白卡片）
③ 数本弹窗有几个真组？
    ├─ ≥ 1 → C2（无白卡片）
    └─ 0   → C1（无白卡片）
```

### 档位与内容承载架构

**C1 / C2（无白卡片）**：
```
┌─ Modal 外壳（底板色 #F5F5F5）────────────┐
│   Header（标题）                          │
│   [字段 / 组标题+字段] 直接在底板上         │
│   Footer（按钮组）                        │
└────────────────────────────────────────┘
```

**C3（有白卡片）**：
```
┌─ Modal 外壳（底板色 #F5F5F5）────────────┐
│   Header（标题）                          │
│   Tabs 导航（仅 C3b）                    │
│   ┌─ 白色卡片（#FFFFFF, radius 12px）─┐  │
│   │  组标题 + 字段                     │  │
│   └────────────────────────────────┘  │
│   Footer（按钮组）                        │
└────────────────────────────────────────┘
```

### 强制约束

- **C1/C2 禁止使用白卡片**——内容直接置于底板上
- **C3 必须使用白卡片**——底板 (#F5F5F5) + 白卡片 (#FFFFFF)
- **C3b 有且仅有 1 张白卡片**——出现 Tabs 后不允许多卡片
- **C1 禁止出现组标题**——按定义 C1 无真组

## Modal 三层文字角色（字重体系）

对话框中的文字**只有三种角色，禁止出现第四种**。

| 层级 | 角色 | font-size / weight / line-height | 出现位置 |
|------|------|--------------------------------|---------|
| 1 | **弹窗标题** | **14 / 600 / 22** | Modal Header，整弹窗唯一 |
| 2 | **组标题**（仅 C2 / C3） | **13 / 600 / 20** | 内容区**真组**的标题——下层必须有 **≥ 2 个独立子字段** |
| 3 | **字段 label** | **13 / 400 / 20** | `label + 单控件` 的 label；Radio group / Checkbox group / Segmented **整体视为一个控件** |

**三层 label 颜色统一为 text-primary (#0D0D0D)**。secondary (#6B6B6B) 仅用于辅助文字/提示/placeholder，**不用于任何 label**。

### 字重判定口诀

```
该 label 下一层有几个独立的子 label？
├─ 0（直接跟控件，或控件为 Radio/Checkbox group/Segmented） → 字段 label  (13 / 400)
├─ 1（只有一个子字段）→ 扁平化为字段 label (13 / 400)，不允许双层
└─ ≥ 2（多个独立子 label + 子控件）→ 组标题 (13 / 600)
```

**判定示例**：

| label | 下一层 | 结论 |
|-------|-------|------|
| 应用到 | 1 个 Select | 字段 label (400) |
| 方向 | 1 个 Radio group（纵向/横向） | 字段 label (400)，Radio group 视为单控件 |
| 纸张大小 | 1 个 Select | 字段 label (400) |
| 页边距（厘米） | 4 个独立子 label + 4 个 Input | **组标题 (600)** |

## Modal 尺寸与内容区宽度预算

### 尺寸选择

| 尺寸 | 宽度 | 适用 |
|------|------|------|
| Small | 480px | 确认弹窗、简单表单 |
| Medium | 640px | 标准表单、设置面板 |
| Large | 800px | 复杂表单、多 Tab 设置 |

### 内容区可用宽度

**C1 / C2（无白卡片）**：可用宽 = 外壳宽 - 34px

| 尺寸 | 可用宽 | 最多列数（每列 ≥ 96px） |
|------|-------|----------------------|
| Small | 446px | 4 列 |
| Medium | 606px | 6 列（临界值） |
| Large | 766px | 7 列 |

**C3（有白卡片）**：可用宽 = 外壳宽 - 58px

| 尺寸 | 卡片内可用宽 | 最多列数（每列 ≥ 96px） |
|------|------------|----------------------|
| Small | 422px | 4 列（临界值） |
| Medium | 582px | 5 列 |
| Large | 742px | 7 列 |

## Modal Footer 按钮规则

| 位置 | 角色 | 按钮类型 + 尺寸 |
|------|------|----------------|
| 底部左侧（辅助操作组） | 默认、文本效果、高级选项等非主流程 | **Secondary Medium** |
| 底部右侧倒数第 2 | 取消 | **Secondary Medium** |
| 底部右侧最后 | 主操作（确认/保存） | **Primary Medium** |
| 底部右侧最后（危险） | 危险主操作（删除） | **Primary Danger Medium** |

- 弹窗 footer 按钮一律 **Medium size (28px)**，不是 Large
- 所有 footer 按钮 `min-width: 72px`
- 取消按钮和确认按钮之间 8px gap
- 左右两组之间 space-between

## 分组通则（适用于所有档位和目标）

- 组与组之间间距 16px
- 组内标题与控件间距 4px
- 禁止用分割线区分组
- 禁止嵌套小卡片（C3 白卡片内也不允许再嵌套）
- 横向并排字段用 grid 布局（务必遵守 [多列布局防溢出规则](../kd-design-language/context-constraints.md#多列布局防溢出规则)）
- C1/C2：section 直接在内容区
- C3：section 在白卡片内
