# Textarea 文本域

- Container padding: `4px 4px 4px 8px`（与 Input 的 `0 4px 0 8px` 不同）
- 默认 border: `#D4D4D4` (line-medium)，比 Input 深一档
- Hover 无颜色变化（已是 line-medium）
- Focus/Error 行为同 Input（仅 border-color，无 box-shadow）

## CSS 来源

完整样式见 [`_css/textarea.css`](_css/textarea.css)，生成 HTML 时直接复制该文件内容到 `<style>` 中。
