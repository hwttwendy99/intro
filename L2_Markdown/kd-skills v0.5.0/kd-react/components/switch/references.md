# Switch · API 参考

> 导入：`import { Switch } from '@kdocs/kdesign'`

#### Switch 属性

| 参数     | 说明           | 类型    | 可选值       | 默认值 |
| -------- | -------------- | ------- | ------------ | ------ |
| checked  | 指定选中的选项 | boolean | --           | --     |
| disabled | 是否禁用       | boolean | --           | false  |
| size     | 尺寸           | string  | small/medium | medium |

#### Switch 事件

| 参数     | 说明                     | 回调参数 |
| -------- | ------------------------ | -------- |
| onChange | 当绑定值变化时触发的事件 | value    |
