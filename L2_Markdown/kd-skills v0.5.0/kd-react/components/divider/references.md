# Divider · API 参考

> 导入：`import { Divider } from '@kdocs/kdesign'`

| 参数              | 说明               | 类型    | 可选值                | 默认值     |
| ----------------- | ------------------ | ------- | --------------------- | ---------- |
| className          | 类名               | string  |      |       |
| style              | 样式               | `CSSProperties`  |      |       |
| type              | 分隔线的类型       | string  | horizontal / vertical | horizontal |
| orientation       | 文字水平的位置     | string  | left/right/center     | center     |
| orientationMargin | 文字水平的偏移位置 | string  | --                    | --         |
| dashed            | 是否为虚线         | boolean | --                    | false      |
