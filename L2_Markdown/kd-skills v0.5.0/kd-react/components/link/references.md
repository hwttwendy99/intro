# Link · API 参考

> 导入：`import { Link } from '@kdocs/kdesign'`

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
| --- | --- | --- | --- | --- |
| type | 类型 | string | `primary` \| `secondary` | secondary |
| icon | 前置图标 | string / HTMLElement | -- | -- |
| disabled | 禁用 | boolean | -- | false |
| underline | 是否需要下划线 | boolean | -- | false |
| href | 跳转链接 | string | -- |  |
| target | 跳转方式 | string | -- | '\_blank'/'\_parent'/'\_self'/'\_top' |
