# Skeleton · API 参考

> 导入：`import { Skeleton } from '@kdocs/kdesign'`

#### Skeleton

| 参数      | 说明         | 类型    | 可选值 | 默认值 |
| --------- | ------------ | ------- | ------ | ------ |
| className | 样式类       | string  |        |
| style     | 样式 style   | Object  |        |
| active    | 是否显示动画 | boolean | false  |
