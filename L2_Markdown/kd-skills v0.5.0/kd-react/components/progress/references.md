# Progress · API 参考

> 导入：`import { Progress } from '@kdocs/kdesign'`

| 参数        | 说明               | 类型   | 可选值                | 默认值  |
| ----------- | ------------------ | ------ | --------------------- | ------- |
| type        | 样式               | string | circle/line           | line    |
| percentage  | 进度               | number |                       | false   |
| status      | 状态               | string | success/error/default | default |
| circleSize  | circle 尺寸        | string | large/medium/small    | medium  |
| circleWidth | 自定义 circle 尺寸 | number |                       |         |
