# Loading · API 参考

> 导入：`import { Loading } from '@kdocs/kdesign'`

| 参数   | 说明 | 类型   | 可选值              | 默认值     |
| ------ | ---- | ------ | ------------------- | ---------- |
| size   | 尺寸 | string | small/medium/large  | medium     |
| layout | 排版 | string | horizontal/vertical | horizontal |
| icon   | 加载指示符 | ReactNode | - | - |
