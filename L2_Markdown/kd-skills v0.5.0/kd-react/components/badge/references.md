# Badge · API 参考

> 导入：`import { Badge } from '@kdocs/kdesign'`

| 参数      | 说明           | 类型                 | 可选值 | 默认值                            |
| --------- | -------------- | -------------------- | ------ | --------------------------------- |
| value      | 显示值       | ReactNode | --     | --            |
| max  | 最大值。超出最大值会显示 ellipsis          | number       | --     |              |
| ellipsis | 超出最大值时，省略号字符 | string      | --     | +                   |
| isDot      | 是否为小红点       | boolean         |     |      false             |
| style      | 自定义样式          | CSSProperties  | --  |    --            |
