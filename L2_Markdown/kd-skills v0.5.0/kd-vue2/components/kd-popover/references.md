# KdPopover · API 参考

> 组件标签：`<kd-popover>` · 包：`@kdocs/kdesign-vue`

## Attributes

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
| --- | --- | --- | --- | --- |
| trigger | 触发方式 | String | click/hover | hover |
| content | 显示的内容 | String | — | — |
| max-width | 最大宽度 | Number | — | 320 |
| placement | 出现位置 | String | top/top-start/top-end/bottom/bottom-start/bottom-end/left/left-start/left-end/right/right-start/right-end | bottom |
| disabled | Popover 是否可用 | Boolean | — | false |
| value / v-model | visible状态是否可见 | Boolean | — | false |
| offset | 出现位置的偏移量 | Number | — | 0 |
| visible-arrow | 是否显示 popover 箭头 | Boolean | — | false |
| open-delay | 触发方式为 hover 时的延迟出现，单位毫秒 | Number | — | 400 |
| close-delay | 触发方式为 hover 时的隐藏延迟，单位为毫秒 | number | — | 100 |
| popper-class | 为 popper 添加类名 | String | — | - |
