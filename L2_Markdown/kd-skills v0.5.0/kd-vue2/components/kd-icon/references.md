# KdIcon · API 参考

> 组件标签：`<kd-icon>` · 包：`@kdocs/kdesign-vue`

## Attributes

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
| --- | --- | --- | --- | --- |
| size | 图标大小 | Number | — | — |
| spin | 旋转动画 | Boolean | — | false |
| fill | 图标颜色(svg 的 fill 颜色) | Pick<CSSProperties, 'color'>(#ff2f2f) | — | — |
| strokeWidth | 图标线条粗细 | Number | — | 1 |
