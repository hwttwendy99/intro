# KdRadio · API 参考

> 组件标签：`<kd-radio>` · 包：`@kdocs/kdesign-vue`

## `RadioGroup` Attributes

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
| --- | --- | --- | --- | --- |
| value / v-model | 绑定值 | string / number / boolean | — | — |
| disabled | 是否禁用 | boolean | — | false |
| layout | 布局方向 | string | horizontal / vertical | horizontal |
