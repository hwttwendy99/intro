# KdTag · API 参考

> 组件标签：`<kd-tag>` · 包：`@kdocs/kdesign-vue`

## Attributes

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
| --- | --- | --- | --- | --- |
| closable | 是否可关闭 | boolean | — | false |
| checkable | 是否可点击 | boolean | — | false |
| color | 背景色 | string | — | — |
| size | 尺寸 | string | medium / small | medium |
| prefix-icon | 按钮前置图标 | Object | — | - |
| checked | 是否选中状态 | boolean | — | false |

## Events

| 事件名称 | 说明 | 回调参数 |
| --- | --- | --- |
| change | 点击 Tag 时触发的事件 | — |
| close | 关闭 Tag 时触发的事件 | — |
