# KdButton · API 参考

> 组件标签：`<kd-button>` · 包：`@kdocs/kdesign-vue`

## Attributes

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
| --- | --- | --- | --- | --- |
| type | 按钮类型 | string | primary / secondary / light | light |
| size | 按钮尺寸 | string | x-large / large / medium / small | large |
| prefix-icon | 按钮前置图标 | Object | — | - |
| suffix-icon | 按钮后置图标 | Object | — | - |
| disabled | 按钮是否为禁用状态 | boolean | — | false |
| loading | 设置按钮loading状态 | boolean | — | false |
| active | 按钮是否为激活状态 | boolean | — | false |
| highlight | 强调按钮 | boolean | — | false |
| danger | 危险按钮 | boolean | — | false |
| icon | 图标按钮 | boolean | — | false |
| menu | 菜单按钮 | boolean | — | false |
