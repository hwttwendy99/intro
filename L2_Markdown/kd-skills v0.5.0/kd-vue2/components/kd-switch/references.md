# KdSwitch · API 参考

> 组件标签：`<kd-switch>` · 包：`@kdocs/kdesign-vue`

## Attributes

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
| --- | --- | --- | --- | --- |
| value / v-model | 绑定值 | boolean / string / number | — | — |
| disabled | 是否禁用 | boolean | — | false |
| loading | 是否展示加载状态 | boolean | — | false |
| activeValue | 该值与value进行匹配, 匹配即为选中 | boolean / string / number | — | true |
| inactiveValue | 该值与value进行匹配, 匹配即为未选中 | boolean / string / number | — | false |
