# KdLink · API 参考

> 组件标签：`<kd-link>` · 包：`@kdocs/kdesign-vue`

## Attributes

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
| --- | --- | --- | --- | --- |
| type | 类型 | string | primary / secondary | secondary |
| underline | 添加下划线 | boolean | — | false |
| disabled | 禁用 | boolean | — | false |
| href | 原生 href 属性 | string | — | - |
| target | 设置跳转方式 | string | _blank / _self | _blank |
| icon | kdicon | Object | — | - |
