# 多语言与国际化

## 文案空间预留

多语言翻译后文案长度会变化，设计稿必须预留扩展空间：

| 原文语言 | 翻译目标 | 长度变化 | 预留规则 |
|---|---|---|---|
| 中文 → 英文 | 英文 | +30% ~ +100% | 预留 100% 扩展空间 |
| 中文 → 日文 | 日文 | 接近相同 | 预留 30% |
| 英文 → 德文/法文 | 欧洲语言 | +20% ~ +40% | 预留 40% |

### 实践规则

1. **按钮文案**：不写死宽度，使用 `padding` 控制内边距，让按钮随文案自适应
2. **导航标签**：使用 `min-width` 而非 `width`，或使用 `text-overflow: ellipsis`
3. **表格列宽**：使用百分比或 `min-width`，不使用固定 px 宽度
4. **标题区域**：多语言标题可能换行，标题容器使用 `auto` 高度

```css
/* 按钮：不要固定宽度 */
.kd-button { min-width: 72px; /* 最小宽度保底 */ }

/* 导航项：允许截断 */
.nav-item { max-width: 200px; overflow: hidden; text-overflow: ellipsis; }

/* 标题：允许换行 */
.page-title { word-wrap: break-word; }
```

## RTL 布局支持

当产品需要支持阿拉伯语/希伯来语等 RTL 语言时：

### 需要翻转的

- 文字对齐方向（left → right）
- 图标方向（箭头、进度方向）
- 面包屑路径方向
- 侧边栏位置（左 → 右）
- 列表项的前导图标位置

### 不需要翻转的

- 数字（阿拉伯数字保持 LTR）
- 品牌 Logo
- 视频/图片内容
- 时间轴方向

### HTML RTL 标注

```html
<html dir="rtl" lang="ar">
```

### CSS RTL 支持

```css
/* 使用逻辑属性替代物理属性 */
/* 推荐 */
padding-inline-start: 8px;
padding-inline-end: 4px;
margin-inline-start: 16px;

/* 不推荐 */
padding-left: 8px;
padding-right: 4px;
margin-left: 16px;
```

## 数字与日期格式

| 地区 | 数字格式 | 日期格式 |
|---|---|---|
| 中国 | 1,265 | 2025-08-07 或 2025年8月7日 |
| 美国 | 1,265 | 08/07/2025 |
| 欧洲 | 1.265 | 07.08.2025 |

### 数字排版

- 数据卡片中的大数字使用 `font-variant-numeric: tabular-nums`（等宽数字）
- 百分比/金额数字右对齐
- 负数使用红色（`text-error`），正增长使用绿色（`text-success`）

## 多语言设计稿标注

在 HTML 设计稿的根元素标注语言：

```html
<html lang="zh-CN">  <!-- 简体中文 -->
<html lang="en-US">  <!-- 美式英文 -->
<html lang="ja">     <!-- 日文 -->
```

如需在同一设计稿中展示多语言对照，使用 `lang` 属性标注具体区域：

```html
<section lang="zh-CN">中文版本内容</section>
<section lang="en-US">English version content</section>
```
