# KDesign Vue3 最佳实践导航

本目录用于沉淀跨组件、跨页面的实践建议，不作为组件级 Skill 触发源。

## 可用主题

- `styles`：样式引入、路径核对、插件接管判断（unplugin / resolver）
- `forms`：表单页字段、校验、提交流程
- `dialog-workflow`：弹窗与异步提交闭环

## 推荐查询方式

- CLI：`kd-vue3 guide <topic>`
- MCP：`kdesign_best_practice`（参数 `topic`）

## 使用原则

- 强约束仍以 Rule 为准（must/never）。
- 具体组件 API 以 `kd-vue3 info/doc/style` 或 MCP 对应工具为准。
