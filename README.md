# Type MD

本地优先的 Markdown 编辑器。单页运行，不用安装、不用构建，打开即可写、改、预览和导出。

适合把 AI 生成的 Markdown 初稿快速改成可交付文档，也适合个人或团队做结构化写作后导出分发。

## 打开方式

在仓库根目录启动本地静态服务：

```bash
python3 -m http.server 4173
```

浏览器访问：

```text
http://127.0.0.1:4173/index.html
```

建议始终通过本地服务打开。直接双击 `index.html` 会走 `file://`，部分浏览器会限制读取 `docs/` 里的预设文档，此时会降级到页面内置文案。

编辑器依赖从 `esm.sh` 加载（CodeMirror、markdown-it 等），首次打开需要能访问外网。文档内容和最近文件都只存在你的浏览器本地，没有后端、也不会上传到服务器。

## 快速开始

打开页面后，左侧「最近文件」会带上两份预设文档，可直接点开：

- `产品功能介绍.md`
- `新用户指南.md`

之后也可以用这三种方式开始写作：

1. **新建**：点击左侧「新建」，进入分栏编辑。
2. **打开本地文件**：点击「打开」选择 `.md` 文件，或把文件拖到首页输入框。
3. **粘贴导入**：把 Markdown 文本贴进首页输入框，点击上传按钮；也可在输入框里按 `Ctrl/⌘ + Enter`。

## 功能

### 三种编辑视图

| 视图 | 说明 |
| --- | --- |
| Source | 源码编辑，适合精确改语法 |
| Preview | 预览区可直接改文字，并回写为 Markdown |
| Split | 左边源码、右边预览，适合边写边看 |

快捷切换：`Ctrl/⌘ + 1` 源码，`Ctrl/⌘ + 2` 预览，`Ctrl/⌘ + 3` 分栏。

### 最近文件

列表按最近修改时间排序，最新的在最上面。支持：

- 关键词搜索文件名和正文
- 重命名、创建副本、删除
- 从文件菜单直接导出

预设文档和普通文档是同一套列表。首次打开时会自动出现那两份示例；之后新建、修改别的文件，它们会按时间往下排。

### 导入与导出

导入支持文件选择、拖拽、粘贴。仅接受 Markdown 文本或 `.md` 文件。

导出格式：

- `.md`
- `.txt`
- `.html`
- `.pdf`
- `.docx`

顶部也可以复制当前内容，或下载当前文稿。

### 预览区格式工具

在预览区聚焦后可用工具栏（或对应快捷键）：

| 操作 | 快捷键 |
| --- | --- |
| 加粗 | `⌘B` |
| 斜体 | `⌘I` |
| 下划线 | `⌘U` |
| 删除线 | `⌘Shift+X` |
| 有序列表 | `⌘Shift+U` |
| 无序列表 | `⌘Shift+Y` |
| 引用 | `⌘Shift+>` |
| 行内代码 | `Ctrl/⌘+E` |

行内代码需要先选中文本，未选中时按钮会呈灰色。

源码区另外支持：`Ctrl/⌘+S` 保存到本地存储，`Ctrl/⌘+F` 聚焦侧边搜索。

### 界面

- 中 / 英切换
- 亮色 / 暗色主题

语言和主题会记在浏览器里，刷新后保留。

## 数据存在哪

当前文稿、最近文件、搜索历史、主题和语言都写在浏览器 `localStorage`。换浏览器或清站点数据后，最近文件列表会按初始状态重新出现两份预设文档。

这是本地工具，不是云端文档库：没有账号、没有同步、也没有服务端存储。

## 目录

```text
intro/
  index.html                 # 页面与全部交互逻辑
  Logo.png
  README.md
  docs/                      # 预设文档
    产品功能介绍.md
    新用户指南.md
  style_skill/               # 页面用到的样式与图标
    tokens.css
    reset.css
    button.css
    segmented.css
    navigation-sidebar.css
    icons/
```

运行时只会加载上述文件。第三方库在页面里按需从 `esm.sh` 引入，不需要 `npm install`。

## 技术说明

- 单页 HTML + CSS + ES Module，无构建步骤
- 源码编辑：CodeMirror 6 + Markdown 语言支持
- 预览渲染：markdown-it，输出经 DOMPurify 过滤
- 预览回写 Markdown：Turndown（含 GFM）
- 导出：jsPDF（PDF）、docx（Word）

## 常见问题

**为什么有的格式按钮是灰的？**  
行内代码只在预览区且已选中文本时可用。

**刷新后文件还在吗？**  
在。最近文件和当前文稿会留在本机浏览器里，直到你删除该项或清除站点数据。

**可以离线用吗？**  
文档读写是本地的。但编辑器脚本来自 CDN，需要至少成功加载过这些依赖。预设 `.md` 文件建议用本地静态服务打开，避免 `file://` 读不到 `docs/`。
